# ❄️🍊 VigieGel Agrumes (Android)

Application Android native (Kotlin, sans publicité ni traqueur) permettant de surveiller le risque de gel nocturne et matinal sur les agrumes grâce aux modèles haute précision **AROME (1,3 km)** et **ARPEGE** de Météo-France.

## Fonctionnalités
- **Température minimale du lendemain (sous abri 2m)** et heure du pic de froid.
- **Indice de gel radiatif au niveau des pots / feuilles** (calculé selon la couverture nuageuse nocturne et le vent).
- **Durée d'exposition sous 0°C** entre 18h00 et 10h00 et rafales maximales nocturnes.
- **Localisation GPS automatique** ou recherche par commune / code postal avec mémorisation.
